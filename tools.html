--- layout: page title: Tools navbar_title: Tools permalink: /tools/ --- # Tools Open-source GIS and geospatial research tools for interpretable, reproducible, and human-centered environmental analysis.

Grain Checker

QGIS plugin · MAUP · Spatial aggregation · Sensitivity analysis

A lightweight QGIS plugin for exploring how spatial aggregation choices affect bivariate point-density relationships. It supports sensitivity checks across multiple spatial units and helps users examine whether observed spatial patterns remain stable under different aggregation schemes.

GitHub Demo

Parcel-Level Land-Use Continuity Tool

QGIS workflow · Historical GIS · Parcel matching · Land-use transition

A QGIS-based workflow for reconstructing parcel-level land-use continuity across historical maps. The tool is designed to address boundary drift in longitudinal spatial analysis and support more consistent reconstruction of land-use transitions over time.
